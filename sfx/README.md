# sfx/

Put your own sound effects here (they are not uploaded). The edit kit looks for these names, any audio format:

- `click` · `whoosh` · `pop` · `ding` · `typing` (the main ones)
- `error` · `hit` · `boom` · `scratch` (optional, for punchier moments)

Use sounds you have the rights to: free packs (for example Pixabay, Mixkit, or ones you made). [earshot](https://github.com/Leonxlnx/earshot) can help pick the cleanest one. A missing name is skipped, never faked.
